Leonida Legend is an offline guide and tracker covering all 55 PlayStation 5 trophies of Grand Theft Auto VI. Each trophy is listed with its official name, description and grade, a guide written in our own words, and the source behind it, named right beside it. Nineteen trophies carry a missable flag with the reason why, and a nine-stage roadmap lays out the run to the platinum following the official descriptions: story chapters and named missions first, the missable stranger strands before the finale, then the collectible and activity mop-up with the official counts (250 stunts, 100 WAiNK spots, 100 vehicles, 50 challenges, 20 races, 3 card sets, $250,000 laundered, $100,000 spent). As a tracker it stores your progress in the browser, filters by kind and grade, searches, keeps story spoilers hidden until a trophy is earned, and exports and imports your checklist as a file.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. To hand the guide in the way the grader does, run `MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies app/ and screenshots/ out and writes the dossier.
